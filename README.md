# Killer Instincts 

A fast-paced 2D action platformer built with Godot Engine where you punch, shoot, and boost your way through enemies!
[play now!](https://terigames.itch.io/killer-instincts)
## What's This About?

You control a badass character who can:
- 🥊 **Throw punches** to knock out enemies
- 🔫 **Pick up guns** and blast away
- ⚡ **Grab power-ups** like speed boosts and double jumps
- 🤸 **Move slick** with crouching, jumping, and smooth animations

## Controls

- **Arrow Keys / WASD** - Move left/right
- **Space** - Jump (double jump with Jump Boost!)
- **Down Key** - Crouch
- **Attack Button** - Punch or shoot (if you have a gun)
- **Right Click** - Radial menu (coming soon™)

## Power-Ups

- **🔫 Gun** - Pew pew! Shoot bullets instead of punching
- **🚀 Speed Boost** - Gotta go fast! 2x speed for 10 seconds
- **⬆️ Jump Boost** - Double jump ability for 15 seconds

All power-ups show a countdown timer so you know when your fun is about to end.(except the gun)

## Features

- Smooth character animations with multiple states (idle, walk, jump, crouch, attack)
- Dynamic collision shapes that switch between standing and crouching
- Gun and melee combat systems
- Timed power-up system with visual feedback
- Radial menu system (WIP)

## Getting Started

1. Clone this repo
```sh
git clone https://github.com/yourusername/killer-instincts.git
```

2. Open in Godot Engine (4.x)

3. Hit F5 and start punching things!
